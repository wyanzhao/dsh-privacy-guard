# DSH 隐私替换

纯本地、确定性规则的 DSH Host 插件：将**新 prompt** 中命中的敏感值替换为一个 `*` 后继续发送。无云端检测、运行时第三方依赖、可逆映射或随机占位符，**不阻断请求**。

> 这是尽力而为的文本替换，不是完整 DLP 或安全边界。不保证零漏检、零误报，也不清理 DSH 已保存的原文。图片、附件、工具返回和旧历史不在保护范围内。

## 安装与版本

- 支持 Node.js **22.13.0+**；CI 覆盖 22.13.0、24、26 的 Linux/macOS/Windows。
- DSH 适配范围为 `>=0.2.2-rc.1 <0.3.0`；扩展点契约在 DSH 0.2.2-rc.1 上确认。其他版本须重新验证，版本范围不是完整兼容性保证。
- 仅发布到私有 GitHub 仓库；`private: true` 禁止误发布到 npm，代码默认保留全部权利，不授予开源许可证。

```sh
gh repo clone wyanzhao/dsh-privacy-guard
cd dsh-privacy-guard
npm ci --ignore-scripts
npm run check
```

在 DSH 中请求助手将克隆目录作为 bundle 安装，使用插件管理工具的 `install_bundle`，`target` 为该目录的**绝对路径**。此操作影响当前 profile 的所有会话。插件管理显示 `applied` 后，在新会话测试；更新已加载模块时按返回结果重启 DSH。可在插件管理中停用或移除，不删除会话或个人词库。

- `/privacy status`：显示运行版本（当前 **1.4.0**）、哪些内容会/不会脱敏（含子代理消息开关）、词库状态和警告，不调用模型。
- `/privacy preview <文本>`：本地预览，与 admission 使用同一引擎。命令设置 `recordInput: false`，但输出仍在本地命令记录中，漏检内容可能出现在结果中。

## 个人词库：不要上传

默认没有个人词库也可以正常使用内置规则。仓库和分发包只包含空的 `private-terms.example.json`，**不包含真实的 `private-terms.json`**。

推荐将个人词库保存在仓库之外、自己控制的目录，并在用户 Cordis 配置中为本插件设置 `dictionaryPath`（宿主系统的绝对路径，Windows drive/UNC 与 Unix 路径均按宿主解析）。也兼容插件目录下被 Git 忽略的 `private-terms.json`，但外部路径更不易受安装/升级影响。

词库格式：

```json
{ "terms": [] }
```

向 `terms` 添加区分大小写的精确姓名、地址、内部代号等。最多 1000 条、每条 4096 字符、文件 1 MiB。`*` 和旧版 `[REDACTED:...]` 是保留标记，词条不可包含它们；不支持用户正则。

每次 admission（仅当有 text 块需要检查时）/预览都会打开并 `fstat` 词库；文件身份（设备、inode、大小、mtime、ctime）不变时复用已编译规则，变化时才重新读取和编译。文件必须是普通文件，实际读取量有上限。读取失败时继续使用本次运行最后可用词库；没有成功记录则仅用内置规则，`/privacy status` 显示警告。缺少可选默认文件是正常状态，不作为错误；显式配置的路径缺失则会警告。文件错误消息不包含原文、完整敏感路径或解析异常内容。

## 规则覆盖

| 类别         | 支持范围                                                                                                                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 带前缀密钥   | 常见 OpenAI/DeepSeek、Anthropic、GitHub、AWS AKIA/ASIA、Google、Slack、GitLab、Hugging Face、npm、Stripe 外形；`sk-` 需已知前缀（proj/ant/svcacct/admin/or-v1）或 ≥20 位同时含字母和数字的连续字母数字；不验证密钥是否真实/有效 |
| 明确凭据字段 | API key/token、password/passwd/pwd、access/refresh/auth token、client secret、secret key、密码/密钥/口令/令牌及常见带前缀环境变量名                                                                                             |
| 明确赋值     | 冒号、等号、“是”“为”、英文 `is`；中英文引号、反引号、转义引号和闭合多行值                                                                                                                                                       |
| 身份认证     | Bearer 值、明确 Authorization Basic 值、常见 JWT 外形；保留 scheme                                                                                                                                                              |
| URL 凭据     | userinfo（用户名与密码一起遮盖）；已识别凭据查询参数，包括值中的逗号/分号；保留其他参数和 fragment。特殊字符须符合 URI 编码规则                                                                                                 |
| 私钥         | PKCS#8、RSA、EC、OpenSSH、DSA、加密 PEM，BEGIN/END 类型对应。截断/不匹配的私钥从 BEGIN 遮盖到末尾，可能过度遮盖；公钥/证书不按私钥处理                                                                                          |
| 邮箱         | 常见 ASCII 地址、加号标签、子域、常见单引号 local-part；不是完整 RFC/国际化邮箱解析器                                                                                                                                           |
| 电话         | 大陆手机号、+86/0086、常见空格/横线分组；带国家码、括号或分隔符的北美号码。明确 phone/mobile/手机/电话字段可匹配 7–15 位数字。裸十位数不默认当电话                                                                              |
| 身份证外形   | 大陆 18 位格式，排除不存在的日期并校验 ISO 7064 MOD 11-2 校验码；不验证地区或真实性                                                                                                                                             |
| 姓名/地址    | 仅明确标签（含 full name/home address/shipping address）或个人词库；不是通用实体识别                                                                                                                                            |

不因为字符串长或随机就把它当密钥，避免误伤普通哈希、版本、端口和编号。未知格式可使用明确标签或个人词库补充；无标点的自然语言、混淆/编码内容、跨内容块拆分仍可能漏检。带空格的秘密应使用引号明确边界。

## 代码上下文（1.4.0）

字段标签后的**未加引号**值，若明显不是秘密则不替换：

- 类型名与注解：`password: string`、`api_key: Optional[str]`、`token: Option<String>`、`&str`、`None/null/undefined` 等。注解后若跟 `= 字面量`（如 `password: str = "x"`），字面量仍会替换。
- 变量/环境/表达式引用：`$X`、`${X}`、`${{ secrets.X }}`、`process.env.X`、`os.environ[...]`、`os.getenv(...)`、`self.token`、`getPassword()` 等整体调用或已知代码对象的成员访问。
- 占位符：`your-...`、`YOUR_API_KEY`、`xxx`、`***`、`...`、`changeme`、`<...>`。
- `pwd` 后的路径（`/`、`~/`、`./`、`C:\`）或调用；地址标签后的 URL、IP、host:port、MAC、`0x` 地址、文件路径、域名；裸 `token`/`令牌` 后不超过 9 位的整数（`max token: 4096`）。密码类标签后的纯数字仍替换。

带引号的值仍替换，除非整个值就是一个引用或占位符（`"${TOKEN}"`、`"<your-key>"`）。未加引号的值不会吞掉不配对的 `)`，`]`、`}`、`;`、`,` 结束凭据值，句末标点留在值外；值范围以外的文字不改动。

## 子代理与队友消息

DSH 中 `send_message`/团队消息（source `agent-message`）和后台子代理结束通知（`subagent-settled`）也以用户消息进入 inbox。它们由代理基于已脱敏输入生成，替换会破坏代码报告，因此默认**原样放行**。需要时在插件配置中设置 `redactAgentMessages: true`。`runtime-context` 每一步都由 DSH 重新渲染，始终原样放行。

## 替换与 JSON 格式

先在原文收集命中范围，再合并重叠区间替换，避免规则互相破坏。每段敏感值使用固定 `*`，不保留长度或实体对应关系。个人词条去除后再次检查可能新出现的内置规则词边界。

对于**完整有效的 JSON 对象/数组/字符串和有效的 JSON 代码围栏**，先验证再按词法边界投影命中：不删除结构标点或切断转义；命中数字、布尔或 null 的自定义词条时将整个标量改为 JSON 字符串 `"*"`。这保持可解析性，但会改变值类型。自定义词条只命中 JSON 结构标点时不会删除结构；它不是代码删除器。其他文本、JSON 片段、其他编程语言不保证语法保留。

空值/布尔值及对象/数组不因凭据字段标签而整体遮盖；其内部仍可命中独立规则。引号、字段名和周围文字尽量保留。实际输出不自动还原；模型/工具不能从星号恢复密钥。

## 调用点与缓存

仅在 `agent/pre-step` 处理新接收消息的 text 内容块，保留 ID/source 和下游决策字段；未改动的决策、消息数组、消息和内容块原样返回（同一对象）。其他插件的拒绝原样保留；本插件不添加拒绝逻辑，也不使用 `llm/stream` 改写冻结请求。

新消息脱敏一次后进入模型可见历史，后续复用已存文本，不每轮重写历史、不加随机编号/时间戳，尽量保持缓存前缀稳定。规则和词库更新只影响未来新消息。本地测试验证转换器不改原对象及前缀文本不变；**不代表已测量提供商缓存命中，或完成真实 DSH 持久化端到端验证**。

## 重要边界

- 仅处理新 text 块；已有历史、系统上下文、运行时上下文、工具输出/参数、opaque provider metadata 不追溯处理、不阻断；子代理/队友消息默认不处理（见上）。建议在干净的新会话开始使用。
- 图片、文件和未知内容块原样放行，**未脱敏**；无 OCR、PDF/Office 解析，工具读出的附件内容也不处理。
- 不清理 inbox、本地聊天记录、附件、浏览器、日志、备份；原文可能仍留在本地。已发送到服务器的数据无法撤回。
- 不管控 MCP、工具、浏览器或外部 Claude Code/Codex 等进程自行联网。
- 配置项：`dictionaryPath`（绝对路径）、`redactAgentMessages`（布尔，默认 false）；旧版 `blockAttachments` 布尔配置仅兼容接收，不再阻断。无 Settings 表单。
- 代码排除是确定性启发式：形如 `a(b)` 的未加引号密码、以 `$` 开头的未加引号密码、`process.x` 等已知代码对象路径会被当作代码而不替换；请给这类秘密加引号或加入个人词库。

## 质量与发布

```sh
npm ci --ignore-scripts
npm run check
npm audit --audit-level=moderate
```

检查包括 ESLint、Prettier、带覆盖率门槛的合成数据测试、分发包文件白名单及**不含个人词库的干净副本激活测试**。测试不读取开发者真实词库，也不调用云端模型。另有所有权感知的 Host mock 验证禁用/重启时注册清理；mock 不是完整 Cordis 运行时。

运行时无第三方依赖；开发工具准确锁定，CI actions 固定提交且仅有只读权限。详见 CONTRIBUTING.md、SECURITY.md、CHANGELOG.md。所有测试和示例使用虚构数据；不应以测试数量或覆盖率推断隐私检测完备性。图标为原创 SVG，中英文资源随包导出。
